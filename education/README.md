# Les 1 — Mijn eerste algoritme 🦊

Tengu opent een doos. Jij staat tussen John en Jane.
AAN = jouw rij. UIT = stilte. 1 of 0.

## Start

1. Open `database.json`
2. Zet jouw naam op de middelste rij (nu: `Jouw Naam`)
3. Run:

```bash
cd education/mijn-eerste-algoritme
python tengu_eerste_algoritme.py
```

4. Typ dezelfde naam als in de JSON

## Wat je leert

- JSON = de doos
- Python = de opdracht
- Filter op naam = het algoritme
- Werkt of werkt niet. Geen magie.

Les 0 = `education/bushidai_education_tengu.py` (Enter / stop).
Les 2 = dezelfde filter via een API-GET.
